E-Commerce Sales Analysis Using SQL

Project Overview

This is my SQL data analysis project based on an e-commerce business dataset. I used MySQL Workbench to explore sales data and understand business performance.

The main goal of this project was to analyse revenue, profit, customers, products, regions and monthly sales trends.

Dataset Information

The project contains four CSV files:
```
Table       | Records
Customers   | 250
Products    | 60
Orders      | 1,000
Order Items | 1,971
```

Key Business Findings

- Furniture generated the highest revenue and profit.
- Electronics was the only loss-making category.
- Accessories had the highest profit margin at 33.31%.
- The East region generated the highest revenue.
- UPI generated the highest revenue among payment methods.
- August 2025 was the best month for revenue and profit.

Business Recommendations

- Review the cost and pricing of electronics products.
- Focus on profitable product categories.
- Monitor monthly sales performance.
- Study regional sales differences.
- Investigate cancelled and returned orders.
